# Core Pack Sketch Files

This folder contains the official **Sketch design files** for the **Core Pack** used throughout the [Elements][1] ecosystem.

These files are shared openly to make it easier for designers and developers to understand how Core Components are structured, styled, and composed, and to encourage contributions back to Elements itself. If you are building components, experimenting with new ideas, or refining existing ones, this is a good place to start.

All graphics are designed and saved in [Sketch][2] version **2025.3.1 (220691)**..

## Contributing
These files are intended to be worked on, not just viewed. If you see something that could be improved, we would love to see a pull request. This can include:
- Improving existing component layouts or consistency
- Adding missing states or variations
- Refining spacing, alignment, or visual hierarchy

## Notes
- These files reflect the Core Components icons at the time of release
- Not every component or internal state may be represented visually
- The Sketch files are a working reference, not a pixel-perfect UI kit

Elements evolves quickly, and these files are expected to evolve alongside it.
